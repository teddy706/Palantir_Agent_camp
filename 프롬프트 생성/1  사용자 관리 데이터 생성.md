### [수정본 1 : 사용자 관리 데이터 생성 프롬프트]

KT 네트워크 운용 시스템의 사용자 관리 데이터 샘플을 50건 생성해줘. 다음 형식과 규칙을 철저히 따라야 해.

#### 1. 열 구성 (A~R)

- **사용자 그룹 (A):** 아래 두 가지 패턴 중 하나 사용
    
    - 협력사: "연동그룹 / KT협력사"
        
    - KT 정직원: "연동그룹 / 주식회사 케이티 / 네트워크부문 / 서부NW운용본부 / [센터명] / [팀명]" (예: 서부코어운용센터 / 충청코어망제어팀)
        
- **사용자명 (B):** 한국식 성+이름 (2~3글자)
    
- **사용자 ID (C):** 8~9자리 숫자
    
    - 협력사: 91로 시작하는 8자리 (예: 91345577)
        
    - KT 정직원: 10으로 시작하는 8자리 (예: 10150376)
        
- **상태 (D):** "정상"(70%), "휴면 계정 잠금"(25%), "퇴사 잠금"(5%)
    
- **사용자 역할 (E):** 협력사는 "협력사" 또는 빈값(퇴사 시) / 정직원은 "운용자", "중간관리자", "운용자 외 1" 등
    
- **사용자 유형 (F):** 협력사는 "협력사" / 정직원은 "사용자" 또는 "중간관리자"
    
- **계정 만료일 (G) 및 패스워드 만료일 (H):** 협력사는 "2026.MM.DD" 형식 (2026년 6~9월 사이) / 정직원은 "( 만료 안함 )"
    
- **휴면 예정일 (I):** 정상 상태는 "2026.06.XX" ~ "2026.08.XX" / 퇴사 잠금은 "-"
    
- **재직 (J):** "재직" (퇴사 잠금 상태일 때만 "퇴직")
    
- **회사명 (K):** 정직원은 "KT" 또는 빈값 / 협력사는 [(주)지엔텔 123-81-95565, 케이티엠오에스 남부, kt ds, (주)윈스테크넷] 중 선택
    
- **직무 (L), 직책 (M), 직급 (N):** 대부분 빈값, 필요시 "품질 관리", "사원" 기입
    
- **미접속 일수 (O):** 당일 접속은 "-", 미접속은 "7 일", "54 일" 등 (숫자 + 공백 + 일)
    
- **최근 접속 일자 (P):** "2026.MM.DD HH:MM:SS" 형식 또는 빈값
    
- **등록 방법 (Q):** 모두 "연동" 고정
    
- **등록 일자 (R):** "YYYY.MM.DD HH:MM:SS" 형식 (2021년~2026년 사이)
    

#### 2. 필수 지정 데이터 (온톨로지 연결용 핵심 사용자)

다음 3명의 사용자는 반드시 고정 데이터로 생성 결과에 포함시켜줘:

1. `91241746`, 김외주, 정상, 협력사, (주)지엔텔
    
2. `91355412`, 박협력, 정상, 협력사, 케이티엠오에스 남부
    
3. `10152948`, 이정직, 정상, 사용자, KT
    

#### 3. 출력 형식 및 시스템 제약 사항

- **Primary Key(기본키):** '사용자 ID' 컬럼을 고유 식별자(PK)로 지정해줘.
    
- **저장 경로:** 최종 산출물은 반드시 `01.data` 폴더 안에 저장해줘.
    
- 엑셀에 바로 붙여넣을 수 있도록 **탭 구분 테이블(TSV) 형식**으로 출력해줘.
    
- 헤더 행을 포함하여 총 50건의 데이터 행을 생성해줘.
