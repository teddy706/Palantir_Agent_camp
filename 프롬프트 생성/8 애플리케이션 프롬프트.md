온톨로지 구성이 게시되었으므로, 가이드라인에 따라 Workshop 애플리케이션 구축을 진행해줘. KT NW보안팀이 실시간으로 이상행위를 관제하고 조치할 수 있는 [네트워크 보안 이상행위 실시간 관제 대시보드] 앱을 생성하고 `04.application` 폴더에 저장해줘.

#### 1. 레이아웃 디자인
- 단일 페이지 레이아웃 구조로 설정하고, 화면을 상단(KPI)/중단(메인 관제 및 상세)/하단(연관 계획서) 구조로 배치해줘.

#### 2. 위젯 배치 및 데이터 매핑
1. **[상단] KPI 카드 섹션 (현황 요약)**
   - 카드 1: '총 이상행위 탐지 건수' (이상탐지이력 오브젝트의 총 count)
   - 카드 2: '고위험 알람 건수' (장비유형별위험도점수가 4점 이상인 오브젝트 개수)
   - 카드 3: '계획 외 무단접속 건수' (계획이탈여부가 'Y'인 오브젝트 개수)

2. **[중단 좌측] 관제 필터 및 메인 테이블 (Object Table)**
   - 필터 위젯: '계획이탈여부(Y/N)', '즉시경고여부(Y/N)', '장비유형별위험도점수(1~5)' 속성을 다중 선택할 수 있는 필터바 배치.
   - 테이블 위젯: 필터링된 '이상탐지이력' 오브젝트 목록을 표 형태로 출력.
   - 표시 컬럼: ANOMALY_ID, 명령어발생시간, 사용자이름_사번, 장비명, 실행명령어, 장비유형별위험도점수, 계획이탈여부, 즉시경고여부

3. **[중단 우측] 상세 감사로그 정보 패널 (Object Details)**
   - 메인 테이블에서 특정 행(이상행위)을 마우스로 클릭하면, 해당 개체의 상세 정보가 실시간 연동되어 우측 패널에 노출되도록 이벤트(Event)를 바인딩해줘.
   - 패널 표시 항목: 실행 명령어 원문, 위험도 사유, 그리고 온톨로지로 연결된 리눅스 서버 OS 로그의 [로그메시지본문] 및 [통과차단여부].

4. **[하단] 링크 기반 연관 작업계획서 테이블**
   - 메인 테이블에서 선택된 작업자의 사번과 링크(Link Type)로 엮여 있는 '작업계획서' 오브젝트 목록을 표로 출력해줘.
   - 이를 통해 보안팀이 "계획이탈여부 = Y"인 알람을 눌렀을 때, 하단에 실제로 사전 승인된 계획서가 없는지(혹은 다른 장비 계획서인지) 시각적으로 즉시 교차 검증할 수 있도록 셋팅해줘.

#### 3. 대응 프로세스 액션(Action) 버튼 연동
- 우측 상세 정보 패널의 하단 영역에 조치 프로세스를 위한 2개의 버튼을 추가해줘.
  1. **'소명 요청' 버튼**: 클릭 시 온톨로지에서 정의한 [이상행위 소명 요청] 액션 폼 팝업이 뜨도록 연결.
  2. **'즉시 계정 차단' 버튼**: 클릭 시 해당 작업자의 상태를 "보안 차단 잠금"으로 변경하는 [보안 조치 및 계정 차단] 액션이 실행되도록 설정하고, 버튼 스타일은 경고 색상(Red)으로 지정해줘.

설계에 맞춰 대시보드를 생성한 후 저장 및 게시(Publish)하고 완성된 Workshop 앱 링크를 공유해줘.
