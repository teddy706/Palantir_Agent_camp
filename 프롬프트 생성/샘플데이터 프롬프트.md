네트워크 장비 접속 로그 샘플 데이터를 생성해줘. 다음 형식과 규칙을 따라야 해:

**데이터 구조 (17개 컬럼, A~Q열):**

1. **명령어 발생 시간** (A열): YYYY.MM.DD HH:MM:SS 형식, 최근 날짜 기준 시간순 정렬

2. **장비 그룹** (B열): 계층형 조직 구조 ("부문 / 본부 / 센터 / 팀 / 기술분류 / 장비유형" 형식)

   - 예: "네트워크부문 / 서부NW운용본부 / 서부코어운용센터 / 전라액세스망제어팀 / 5G / 삼성_USM"

3. **장비명** (C열): 영문+숫자 조합의 장비 식별자

   - 예: USM_MCMA_VIP, DJ-HeMS105, AMF#13/14/51/52(광주/부산) EMS

4. **대표 IP** (D열): 172.29.xxx.xxx 대역의 내부 IP

5. **접속 프로토콜** (E열): "SSH(SSH)" 고정

6. **사용자 그룹** (F열): 계층형 조직 구조 ("연동그룹 / 회사명 / 부문 / 본부 / 센터 / 팀" 형식)

   - 예: "연동그룹 / 주식회사 케이티 / 네트워크부문 / 서부NW운용본부 / 서부코어운용센터 / 충청코어망제어팀"

   - 협력사의 경우: "연동그룹 / KT협력사"

7. **사용자** (G열): "한글이름(사번)" 형식

   - 정직원 사번: 10으로 시작하는 8자리 (예: 10152948)

   - 협력사 사번: 91로 시작하는 8자리 (예: 91241746)

8. **접속 IP** (H열): 10.xxx.xxx.xxx 대역의 클라이언트 IP

9. **접속 계정** (I열): vsm, hems, imadmin 등 시스템 계정

10. **접속 방식** (J열): "직접" 고정

11. **실행 명령어** (K열): 리눅스/네트워크 장비 CLI 명령어

    - 예: ls, cd, cat, cp, mv, rm, ssh, su -, setm, creboot, RTRV-SYS-NAME; 등

12. **처리 결과** (L열): "실행" 고정

13. **처리 정책** (M열): 빈 값

14. **옵션** (N열): 빈 값

15. **접속 사유** (O열): 빈 값

16. **상세 사유** (P열): 빈 값

17. **Character Set 정보** (Q열): "UTF-8" 고정

**생성 규칙:**

- 50행의 샘플 데이터 생성

- 시간은 1~2초 간격으로 연속적으로 분포

- 동일 사용자가 연속으로 여러 명령어를 실행하는 패턴 포함

- 장비 그룹과 사용자 그룹의 지역명은 서부, 동부, 충청, 전라, 대구, 광주, 부산 등 사용

- 실행 명령어는 실제 시스템 운영에서 사용되는 명령어 패턴 적용

Excel에 바로 붙여넣기 할 수 있는 탭 구분 형식으로 출력해줘.

## 열 구성 (A~R)

1. **사용자 그룹 (A)**: 아래 두 가지 패턴 중 하나 사용

   - 협력사 패턴: "연동그룹 / KT협력사"

   - KT 정직원 패턴: "연동그룹 / 주식회사 케이티 / 네트워크부문 / 서부NW운용본부 / [센터명] / [팀명]"

     - 센터명 예: 서부코어운용센터, 전남/전북액세스운용센터, 충남/충북액세스운용센터

     - 팀명 예: 전라액세스망제어팀, 충청액세스망제어팀, 인증/VoLTE운용팀, NW보안팀, 전남엔지니어링팀, 제주엔지니어링팀, 충북엔지니어링팀, 충청코어망제어팀

2. **사용자명 (B)**: 한국식 성+이름 (2~3글자), 성은 김/이/박/최/강/고/구/권/곽 등

3. **사용자 ID (C)**: 8~9자리 숫자

   - 협력사: 9로 시작하는 8자리 (예: 91345577)

   - KT 정직원: 10으로 시작하는 8자리 (예: 10150376)

4. **상태 (D)**: 다음 중 하나 (비율: 정상 70%, 휴면 계정 잠금 25%, 퇴사 잠금 5%)

   - "정상"

   - "휴면 계정 잠금"

   - "퇴사 잠금"

5. **사용자 역할 (E)**:

   - 협력사: "협력사" 또는 빈값(퇴사 시)

   - KT 정직원: "운용자", "중간관리자", "운용자 외 1", "중간관리자 외 1"

6. **사용자 유형 (F)**:

   - 협력사: "협력사"

   - KT 정직원: "사용자" 또는 "중간관리자"

7. **계정 만료일 (G)**:

   - 협력사: "2026.MM.DD" 형식 (2026년 6~9월 사이)

   - KT 정직원: "( 만료 안함 )"

8. **패스워드 만료일 (H)**:

   - 협력사: "2026.MM.DD" 형식 (2026년 6~9월 사이)

   - KT 정직원: "( 만료 안함 )"

9. **휴면 예정일 (I)**:

   - 정상 상태: "2026.06.XX" ~ "2026.08.XX" 형식

   - 퇴사 잠금: "-"

10. **재직 (J)**: "재직" 또는 "퇴직" (퇴사 잠금 상태일 때만 "퇴직")

11. **회사명 (K)**:

    - KT 정직원: "KT" 또는 빈값

    - 협력사: 아래 회사명 중 선택

      - "(주)지엔텔 123-81-95565"

      - "케이티엠오에스 남부"

      - "케이티엠오에스 북부"

      - "(주)이노와이어리스"

      - "에스큐아이소프트(주)"

      - "노키아솔루션앤네트웍스코리아"

      - "노키아씨멘스네트웍스코리아"

      - "(주)에릭슨코리아파트너스"

      - "(주)윈스테크넷"

      - "소프트퓨전"

      - "kt ds"

12. **직무 (L)**: 대부분 빈값, 가끔 "품질 관리"

13. **직책 (M)**: 빈값

14. **직급 (N)**: 대부분 빈값, 가끔 "사원"

15. **미접속 일수 (O)**:

    - 오늘 접속: "-"

    - 미접속: "1 일", "2 일", ... "86 일" 형식 (숫자 + 공백 + 일)

16. **최근 접속 일자 (P)**:

    - "2026.MM.DD HH:MM:SS" 형식

    - 미접속 일수가 많거나 빈값일 수 있음

17. **등록 방법 (Q)**: 모두 "연동"

18. **등록 일자 (R)**: "YYYY.MM.DD HH:MM:SS" 형식 (2021년~2026년 사이)

## 데이터 일관성 규칙

- "퇴사 잠금" 상태일 때: 사용자 역할(E) = 빈값, 재직(J) = "퇴직", 휴면 예정일(I) = "-"

- KT 정직원일 때: 계정/패스워드 만료일 = "( 만료 안함 )"

- "휴면 계정 잠금" 상태일 때: 미접속 일수가 높은 편 (7일 이상)

- 협력사와 KT 정직원 비율은 약 7:3

- 탭으로 구분된 테이블 형식
