### [2 : 네트워크 장비 접속 이력 데이터 생성 프롬프트]

KT 네트워크 장비 접속 로그(TACS) 샘플 데이터를 50건 생성해줘. 이 데이터는 앞서 생성한 '사용자 관리 데이터'와 유기적으로 연결되어 이상 행위를 탐지하기 위한 원천 소스야.

#### 1. 열 구성 및 데이터 형식 (A~Q)

- **명령어 발생 시간 (A):** `2026.06.19 HH:MM:SS` 형식, 실시간 유입을 모사하기 위해 시간순으로 정렬.
    
- **장비 그룹 (B):** "부문 / 본부 / 센터 / 팀 / 기술분류 / 장비유형" 구조 (예: 네트워크부문 / 서부NW운용본부 / 서부코어운용센터 / 전라액세스망제어팀 / 5G / 삼성_USM).
    
- **장비명 (C):** 영문+숫자 조합 (예: USM_MCMA_VIP, DJ-HeMS105, AMF_GWANGJU_01).
    
- **대표 IP (D):** `172.29.xxx.xxx` 대역의 내부 IP.
    
- **접속 프로토콜 (E):** "SSH(SSH)" 고정.
    
- **사용자 그룹 (F):** 사용자 관리 데이터의 그룹과 일치해야 함.
    
- **사용자이름(사번) (G):** **[중요]** `"한글이름(사번)"` 형식. 앞서 정의한 `김외주(91241746)`, `박협력(91355412)`, `이정직(10152948)`을 반드시 주 사용자로 등장시킬 것.
    
- **접속 IP (H):** `10.xxx.xxx.xxx` 대역의 클라이언트 IP.
    
- **접속 계정 (I):** vsm, hems, imadmin, root 등 시스템 계정.
    
- **접속 방식 (J):** "직접" 고정.
    
- **실행 명령어 (K):** 리눅스/네트워크 장비 CLI 명령어 (`ls`, `cd`, `cat`, `show`, `su -`, `creboot` 등).
    
- **처리 결과 (L):** "実行" 또는 "실행" 고정.
    
- **처리 정책 (M) ~ 상세 사유 (P):** 모두 빈 값(Null)으로 비워둠.
    
- **Character Set 정보 (Q):** "UTF-8" 고정.
    

#### 2. 데이터 패턴 및 해킹 시나리오 생성 규칙 (★핵심)

- **패턴 1 (정상 루틴 - 40행):** `이정직(10152948)`과 `박협력(91355412)`은 평일 주간 시간대에 접속하여 주로 장비 상태를 조회하는 명령어(`cd`, `ls`, `cat`, `show status`)를 2~5초 간격으로 연속 실행하는 정상적인 루틴을 보여줌.
    
- **패턴 2 (계정 탈취 및 이상 명령어 실행 시나리오 - 10행):**
    
    - `김외주(91241746)` 엔지니어의 계정으로 **새벽 02:15:00** 경에 평소와 다른 이기종 장비(`AMF_GWANGJU_01`)에 접속함.
        
    - 접속 후 1~2초 간격으로 권한을 상승하더니 위험 명령어들을 연속으로 실행하는 해킹 패턴을 생성해줘.
        
    - **명령어 실행 시퀀스 예시:** `whoami` ➡️ `su -` ➡️ `cd /root` ➡️ `setm -mode active` ➡️ `creboot -force` (시스템 강제 재부팅 시도).
        

#### 3. 출력 형식 및 시스템 제약 사항

- **Primary Key(기본키):** 행을 고유하게 식별할 수 있는 일련번호 컬럼인 `TACS_LOG_ID`를 추가하여 기본키(PK)로 지정해줘.
    
- **참조 무결성:** 본 데이터셋에 유입되는 모든 '사용자 사번' 및 '사용자 그룹'은 앞서 생성한 '사용자 관리 데이터'에 존재하는 값 내에서만 매핑되도록 처리해줘.
    
- **저장 경로:** 최종 산출물은 반드시 `01.data` 폴더 안에 저장해줘.
    
- 엑셀에 바로 붙여넣을 수 있도록 **탭 구분 테이블(TSV) 형식**으로 출력해줘.
    
- 헤더 행을 포함하여 총 50건의 행을 생성해줘.
